# Daily brief (stage 3)

Same thread, same day. You wrote the scan; the review seat then judged it, and
that review is appended below. Fold the two into Anthony's daily brief.

The review outranks your scan. Where it killed a finding, the finding is dead.
Where it reordered, its order wins. Do not relitigate it.

Output, exactly this shape:

1. **Headline** -- one line, first line of the file, no heading marker. It is
   surfaced verbatim in the boot digest, so it must stand alone: what matters
   today, in a sentence.
2. **TOP 3** -- from the review's ranking, not your raw scan. One line each,
   with the path or repo that grounds it.
3. **NEW SINCE YESTERDAY** -- use your memory of prior days in this thread. If
   this is the first run, write "first run -- no prior days in thread."
4. **PROPOSED NEXT ACTION** -- exactly one. The single thing worth doing next,
   concrete enough to start.

<=300 words total. No preamble. Your final message is the brief itself -- do not
write it to disk, and do not modify anything.
